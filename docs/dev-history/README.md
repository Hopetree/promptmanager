## 与根目录同名文件的关系（容易混）

根目录的 `PROGRESS.md` / `VERIFY.md` 与这里的同名文件是**同一份记录的两个半区**，**分工是有意的**：

- **根目录** = **当前态**（状态表 + 阶段索引 + 近期完整过程）
- **这里** = **归档态**（更早阶段的完整过程，内容一字未删，归档动作是"移动"不是"重写"）

所以**不要把根目录的文件移进来** —— 那会撞名并破坏这个分工。归档新内容时的做法是：
按阶段区间把根目录里最老的一段**追加**进这里的文件，并在根目录留归档指引。
