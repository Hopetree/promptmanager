# `docs/` 目录索引

> **规则**：`docs/` **只放最终状态文档**（会随版本更新、但始终代表当前口径）。
> 过程产物进 `tmp/`（`.gitignore` 已忽略，永不入库）。判据是**"还会不会变"**：
> 接口参考、依赖台账、版本规则会更新但**始终是当前口径** ⇒ 属 `docs/`；
> 需求合同、进度日志、验收记录、一次性验收脚本 ⇒ **属本地 `tmp/dev-process/`，不入库**。

| 文件 | 角色 | 何时读 |
| --- | --- | --- |
| [`api.md`](api.md) | **HTTP API / CLI / MCP 接口参考**：认证、环境变量、端点、契约、错误码 | 写集成 / 调接口 / 改端点 |
| [`development.md`](development.md) | **开发者文档**：项目结构、构建与测试命令、质量门、验证方式 | 上手开发 / 构建 / 测试 |

| [`versioning.md`](versioning.md) | **版本管理细则**：semver 判据、tag 约定、发版流程与**发版检查单**、`schema_version` | 发版 / 改导出格式 |

## 两条容易搞错的边界

1. **`docs/` 不是草稿区**。写过程记录、临时对账、探索笔记 → `tmp/`（永不入库）。
2. **仓库里不放过程态**（2026-09-30 起）。需求合同、进度日志、验收记录、一次性验收脚本、设计打样归档
   都在**本地** `tmp/dev-process/`（镜像本仓库布局），**不是交付物、不要再提交回来**。
   它们的位置与用途见 [`../AGENTS.md`](../AGENTS.md) 第 13 节。
